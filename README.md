# 값콕 Hub

값콕 Hub는 평가 자료를 수집하고 분석하는 프로그램입니다. 설치 파일과 사용 방법을 이곳에서 제공합니다.

## 설치

[최신 설치 파일 받기](https://github.com/gapkok/gapkok1/releases/latest)

| 운영체제 | 설치 파일 |
|---|---|
| Windows 64비트 | `GapKok-Hub-2026.11.12.2.exe` |
| macOS Apple Silicon (M 계열) | `GapKok-Hub-2026.11.12.2.dmg` |
| Linux x86-64 | `GapKok-Hub-2026.11.12.2.run` |

- **Windows:** EXE를 실행하고 설치 화면을 따라 진행합니다. 필요한 구성요소 설치에 관리자 권한이나 재부팅이 필요할 수 있습니다.
- **macOS:** DMG를 열어 앱을 응용 프로그램 폴더에 넣고 실행합니다.
- **Linux:** 받은 파일에 실행 권한을 준 뒤 실행합니다.

```sh
chmod +x GapKok-Hub-2026.11.12.2.run
./GapKok-Hub-2026.11.12.2.run
```

설치 중 운영체제의 확인 화면이나 Docker의 사용 조건 확인이 나오면 내용을 확인하고 진행하세요.

## 값콕 연결

1. Hub를 실행한 뒤 열리는 브라우저에서 값콕에 로그인합니다.
2. 사용할 조직을 선택해 연결합니다.
3. Hub 준비가 끝나면 값콕에서 자료 수집과 분석을 시작합니다.

공통 실행 파일은 연결 후 자동으로 내려받습니다. GitHub 계정이나 별도 다운로드 토큰은 필요하지 않습니다. 이미 연결된 조직의 Hub를 다른 컴퓨터로 옮길 때는 값콕의 **설정 → Hub**에서 이전 절차를 이용하세요.

## 업데이트

값콕의 **설정 → Hub**에서 자동 또는 수동 업데이트를 선택할 수 있습니다. 진행 중인 작업이 끝난 뒤 새 버전을 적용하며, 기존 평가환경·자료·결과와 계정 연결은 유지합니다.

연결이나 다운로드가 멈추면 인터넷 연결과 Docker 실행 상태를 확인하고 Hub를 다시 실행하세요. 해결되지 않으면 값콕의 문제 신고 기능으로 알려 주세요.
